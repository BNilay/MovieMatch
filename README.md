MovieMatch is an AI-powered movie recommendation application designed to help groups decide what to watch together.

Users enter the number of participants, and each person submits a movie they like. The system analyzes the selected movies using AI and suggests new films that best match the group's shared taste.

## 🚀 How It Works

1. Enter the number of people.
2. Each participant submits a favorite movie.
3. The AI analyzes genres, themes, and similarities.
4. The system generates movie recommendations based on common preferences.
